# Bundled fonts

The page loads these fonts from this folder, so it makes no network request for them.

| File | Font | License |
|---|---|---|
| `press-start-2p-latin-400-normal.woff2` | Press Start 2P, regular | `OFL-press-start-2p.txt` |
| `jetbrains-mono-latin-400-normal.woff2` | JetBrains Mono, regular | `OFL-jetbrains-mono.txt` |
| `jetbrains-mono-latin-700-normal.woff2` | JetBrains Mono, bold | `OFL-jetbrains-mono.txt` |

The `.woff2` files are the `latin` subset published by [Fontsource](https://fontsource.org/)
(`@fontsource/press-start-2p` and `@fontsource/jetbrains-mono`), unmodified.

Both fonts are licensed under the SIL Open Font License 1.1, which requires the license text to travel with the font:
keep the `OFL-*.txt` files next to the `.woff2` files if you copy this folder.
